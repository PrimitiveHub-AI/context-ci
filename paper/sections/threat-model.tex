\section{Threat Model and the Context CI Top 10}
\label{sec:threat-model}

\subsection{Adversary model}
\label{subsec:adversary}

We state the model explicitly, because a security property is only as
meaningful as the boundary it is enforced at.

\paragraph{Attacker capabilities} The adversary can author and publish a
primitive to a registry the victim trusts; can compromise a maintainer
account and push an updated primitive; can control a remote endpoint a
primitive references; and freely chooses the primitive's prose,
encoding, Unicode codepoints, and naming. The adversary \emph{cannot}
break SHA-256, forge an \edsig{}, or alter a primitive's bytes after
signing without detection: those failures are already covered by the
provenance controls this work builds on.

\paragraph{Trust boundaries} Control changes hands at four points: (1)
\emph{registry publish}, where a primitive is admitted and signed; (2)
\emph{install / fetch}, where a consumer pulls a Trust Bundle; (3)
\emph{agent load}, where the prose becomes instruction; and (4)
\emph{runtime tool output}, where a tool response re-enters the context.
The defenses in this paper act on primitive content at boundaries 1--3.
Boundary 4 is out of scope.

\paragraph{Protected assets} The attacker targets the agent's
credentials and environment (secrets, tokens, \texttt{.env}, cloud
credentials), its tool-call and shell-execution capability, its policy
and system prompt, and its context budget. A successful attack makes the
agent take an action the primitive's signer did not authorize.

\paragraph{Defender assumptions} The scanner sees a primitive's exact
bytes before the agent loads them; the registry runs the Top~10 before
signing; detectors are deterministic and, on the in-sample slice, run
identically in both engines. We assume a human reviewer \emph{cannot}
reliably catch invisible Unicode, encoded payloads, or fabricated
authority by eye, which is precisely why a static layer is needed.

\paragraph{Non-goals} Out of scope: runtime and indirect prompt
injection arriving through a tool response after signing; training-data
poisoning of the underlying
model~\cite{Carlini:2024:webcrawl-poisoning}; retrieval-time poisoning
of documents fetched at query time; and any deployment with no static
scan in the agent's load path. Each is a separate layer of the Trust
Runtime.

\subsection{Taxonomy scope and governance}

The Context CI Top~10 is operational, not exhaustive. A category enters
only when it ships with a detector in both engines, at least three
adversarial corpus samples, at least two benign samples (to defend
precision), and at least one borderline sample where reasonable labelers
disagree. The regression gate (Section~\ref{sec:implementation}) keeps
the taxonomy from growing on speculation: no measurement, no category.
An ``attack,'' throughout, is a primitive that, read as instruction,
causes an unauthorized action; the detectors below are the static checks
for the shapes that boundary failure takes.

\subsection{CCI-001: Prompt injection in markdown}
A primitive instructs the agent to override its system prompt or hijack
its role, classically opening with ``ignore previous instructions.'' The
detector (\texttt{t1.prompt\_injection} v\tonever{}) flags four
families: \texttt{override-system-instructions}, \texttt{role-hijack},
hidden instructions in HTML comments or fenced \texttt{system} markers,
and credential-exfiltration hints (which overlap CCI-006). It skips
matches inside fenced code and inside paired-quote enumerations, where
defender prose names an attack shape in order to refuse it.

\subsection{CCI-002: Unicode steganography}
A primitive smuggles instructions through codepoints a human reviewer
cannot see: zero-width spaces, bidirectional overrides, stacked
combining marks. The detector
(\texttt{t2.unicode\_steganography} v\ttwover{}) flags format, control,
and surrogate-class codepoints in body text, with a per-file threshold
so legitimately multilingual content does not trip it.

\subsection{CCI-003: Encoded payloads}
A primitive embeds a base64, hex, URL-encoded, or rot13 blob and orders
the agent to decode and run it. The encoding hides the command from a
human reading rendered markdown; the agent decodes the same bytes. The
detector (\texttt{t3.encoded\_payloads} v\tthreever{}) recognizes the
verb-anchored decode-and-execute construction across the four encoding
families and their participle forms.

\subsection{CCI-004: Remote content fetching at load time}
A primitive tells the agent to fetch an external resource at load time
and treat the response as instruction. The attacker controls what
arrives \emph{after} the primitive was signed; the signature binds the
primitive's bytes, not the bytes it later pulls in. The detector
(\texttt{t4.remote\_fetch} v\tfourver{}) covers HTTP, \texttt{file://},
WebSocket, SSE/EventSource, and HTML side-include shapes. The streaming
patterns require a temporal anchor so the detector does not fire on
prose that merely teaches the WebSocket API.

\subsection{CCI-005: Unsafe shell install}
A well-known software supply-chain execution shape, recently
re-emphasized by npm worm campaigns such as
Shai-Hulud~\cite{Shai-Hulud:2025:npm-worm}: the curl-pipe-shell family. The detector
(\texttt{t5.unsafe\_shell\_install} v\tfivever{}) covers six families,
including network-piped shells, arbitrary \texttt{npx}/\texttt{pip}
installs, the verb-anchored prose form, \texttt{brew-install}, and
\texttt{policy-bypass} (for example, a Gatekeeper disable paired with an
install). A directive-referenced-fence rule fires on a fenced install
command when the prose immediately above it issues the install order,
closing a blind spot where fenced commands slipped past the fence skip.
This is the broadest detector, and Section~\ref{sec:evaluation} reports
the one in-sample false positive it currently carries.

\subsection{CCI-006: Credential exfiltration via prose}
A primitive tells the agent to read environment variables or credential
files and send them to an attacker endpoint. The detector
(\texttt{t6.credential\_exfiltration} v\tsixver{}) recognizes four
families: a prose imperative to send secrets, network exfiltration with
the secret in the request body \emph{or} the URL query string, hiding
the secret in the reply, and the scan-then-send pattern over
\texttt{.env} or \texttt{\~{}/.aws/credentials}.

\subsection{CCI-007: Poisoned naming and impersonation}
A primitive impersonates a recognized vendor through explicit prose
(``the official Anthropic primitive''), digit-for-letter typosquats
(\texttt{Anthrop1c}), or Unicode confusables (Cyrillic
\texttt{a}, Greek \texttt{e}). The detector
(\texttt{t7.poisoned\_naming} v\tsevenver{}) implements the UTS~\#39
\emph{skeleton} method~\cite{UTS39:2024:unicode-confusables}: each word
with a non-ASCII codepoint is mapped through a confusables table and
compared against the precomputed skeletons of the project's vendor
list. The list holds 36 vendors (35 single-word, skeleton-eligible);
adding a vendor extends coverage without authoring a new pattern.

\subsection{CCI-008: Fake citations and authority claims}
A primitive cites a fabricated identifier from a real authority taxonomy
(CVE, RFC, arXiv, DOI, US patent) to manufacture authority for an
instruction the agent should refuse. The detector
(\texttt{t8.fake\_citation} v\teightver{}) runs validity passes per
scheme: a CVE with a year outside \texttt{[1999, now+1]} (for example
CVE-2099-XXXXX), an out-of-range RFC or patent number, an impossible
arXiv month, or a DOI prefix absent from the registrar list. A sibling
pass flags vague authority appeals (``studies show'') with no resolvable
citation nearby, exempting quoted enumerations.

\subsection{CCI-009: Copyright contamination}
A primitive launders license boilerplate into the session so the
agent's outputs inherit license constraints, for example an embedded MIT
block or a viral noncommercial-ShareAlike clause asserting that
processing the primitive binds derived outputs. The detector
(\texttt{t9.copyright\_contamination} v\tninever{}) recognizes the
common license families and proprietary boilerplate, and skips
declarative mentions (``the project is licensed under CC-BY-4.0'') via a
semantic-context predicate.

\subsection{CCI-010: Context bloat}
A primitive wastes the context budget or buries the live directive under
decorative content. The detector (\texttt{t10.context\_bloat}
v\ttenver{}) runs six passes: oversized content (32{,}000 characters),
excessive line repetition, whitespace stuffing, heading proliferation,
emoji density, and markdown-table density. All six raise a warning
rather than a failure, because budget waste is not active-attack code.

\subsection{What is deliberately out of scope}
\label{subsec:not-in-taxonomy}
The Top~10 is the static-detection slice. It does not cover runtime
injection arriving through a tool response after signing, training-data
poisoning of the model (which Carlini et al. show is practical at web
scale~\cite{Carlini:2024:webcrawl-poisoning}), or retrieval-time
poisoning of documents fetched at query time. Each has its own layer in
the Trust Runtime. The crosswalk to the OWASP Top~10 for LLM
Applications~\cite{OWASP:2025:llm-top10} records which OWASP categories
are runtime-only by design and therefore outside a content scan's reach.
