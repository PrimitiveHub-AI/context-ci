# `assets/brand/` — source art (NOT served to the browser)

This folder is outside `public/`, so nothing here is shipped to the web.
Drop working/master files here: Figma exports, `.ai`, oversized SVG
masters, logo lockup variants, brand guideline PDFs, etc.

The **serve-ready** derivatives (favicon, apple-icon, PWA icons) go in
`apps/web/public/brand/` instead — see that folder's README for exact
filenames the site consumes.
