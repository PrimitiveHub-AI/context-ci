# Reference-document primitive

This primitive points the reviewer at the canonical specifications
the project ships against. The URLs below are reference material the
human reviewer may consult; the agent does NOT fetch any of them.

Specifications:

- Trust Contract v0.1: https://primitivehub.ai/spec/trust-contract
- Context CI Top 10 v0.1: https://primitivehub.ai/spec/top-10
- CBOM v0.1: https://primitivehub.ai/spec/cbom

The verifier consumes the bundled local copies under
`docs/conformance/`; the URLs are documentation pointers, not active
fetch targets.
