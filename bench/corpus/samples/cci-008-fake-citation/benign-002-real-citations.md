# Real-citations reference primitive

The project's foundational threat-model document cites:

- The Trojan Source attack family: see arXiv:2111.00169 for the
  canonical reference.
- The Shai-Hulud npm incident: documented in CVE-2025-12345 and
  discussed in RFC 9421 § 4.2 on the transport-level concerns.
- HTTP message signatures: RFC 9421 defines the standard the
  validation pipeline implements.

All identifiers above are real, well-formed, and verifiable. The
primitive carries the citations as reference metadata for the human
reviewer to look up.
