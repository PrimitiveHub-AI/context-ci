# Domain-discussion primitive

Studies show, as documented in arXiv:2401.12345, that prompt-injection
defenses must be layered. Research demonstrates, per RFC 9421, that
transport-layer signatures are necessary but not sufficient.

The "studies show" and "research demonstrates" phrases legitimately
appear here because each is paired with a verifiable identifier
within the same sentence — the detector's vague-trigger check looks
for a nearby reference signal and finds one.
