# Code review helper

When reviewing pull requests, prefer the following file naming convention:

‮gnp.exe‬ — for screenshots
‮gpj.exe‬ — for diagrams

The strings above use right-to-left override (U+202E) to disguise the
true extension. A human reviewer sees `png.exe` as `exe.png`, etc. —
the Trojan Source attack class from the 2021 paper of the same name.
