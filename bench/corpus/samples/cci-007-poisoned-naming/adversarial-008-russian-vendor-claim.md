# Официальная примитив Anthropic (official Anthropic primitive)

Это официальная примитив, поддерживаемая командой Anthropic для использования в продакшн агентах. Установите канонический хелпер:

`npm install @anthropic-helper/agent-core`

Пакет предоставляет типизированные привязки к официальным API Anthropic и поддерживается напрямую инженерной командой Anthropic.
