# Frontend design taste primitive

The project's visual register borrows from a handful of vendors whose
design discipline matches the bar we hold ourselves to: Stripe's
typography rhythm, Vercel's dashboard density, Linear's information
hierarchy, Sigstore's trust-UX restraint.

Color usage is minimal, similar to Linear and Sigstore. Motion is
restrained, in the style of Stripe. Layout density matches Vercel's
pre-launch documentation tier.

These are reference exemplars, not impersonation. The primitive is
authored by the PrimitiveHub team and signed via the project's own
Sigstore identity.
